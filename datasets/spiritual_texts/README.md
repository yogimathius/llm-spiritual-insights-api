# Inherited Text Corpus

This directory contains 36 historical text files inherited from the prototype. The current API, deliberation engine, and evaluation benchmark do not load them. They are preserved as archival research material.

[`MANIFEST.csv`](MANIFEST.csv) records each filename, byte count, SHA-256 checksum, and any source notice found near the beginning of the file. A notice is a clue about the copy's lineage, not proof of where this repository obtained it or permission to reuse it. Reuse rights remain unverified for every file.

Before using a text in a feature, benchmark, distribution, or model workflow, record its exact edition and translator, acquisition URL or donor, reuse terms for the relevant jurisdiction, and any required attribution or permission. Keep user supplied evidence and model interpretation distinct from these source texts.
